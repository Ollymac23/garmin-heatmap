# garmin-heatmap
heatmap for activities on garmin

upload gpx files to data and it will create a map to output

How to run
Use the following link to test:
http://garmin-heatmap.onrender.com/
or clone the repository to your local computer and run heatmap.py
It contains a small sample of some of my personal activites (not where I live!) to demonstrate the basic funtion of the program thusfar.

The program uses plotly, gpxpy and nicegui to render a very basci (for now) ui for creating and veiwing heatmaps of a collection of gpx files. fun for visualizing where you have been the most across the world during tracked activites.
